# NLP-Project
# Emotion Detection in Text Using NLP (Jupyter Notebook)

## 📌 Project Overview

This project demonstrates **Emotion Detection from text using Natural Language Processing (NLP)** implemented entirely in a **Jupyter Notebook (nlp.ipynb)**. The notebook covers text preprocessing, feature extraction, model training, evaluation, and emotion prediction in a step-by-step, easy-to-understand manner.

It is ideal for **learning NLP concepts, ML workflows, and emotion classification** in a single interactive notebook.

---

## 📁 Project Files

```
Emotion-Detection-in-Text-Using-NLP/
│
└── nlp.ipynb        # Complete NLP pipeline notebook
```

---

## 🎯 What This Notebook Covers

* 📝 Loading and exploring emotion dataset
* 🧹 Text cleaning & preprocessing
* 🔤 Tokenization & stopword removal
* 🌱 Stemming / Lemmatization
* 📊 Feature extraction using TF-IDF
* 🤖 Training ML model for emotion detection
* 📈 Model evaluation
* 😀 Emotion prediction on new text

---

## 🛠️ Technologies Used

### 🔹 Programming Language

* **Python**

### 🔹 Libraries & Tools

* **Jupyter Notebook** – Interactive development
* **NLTK** – Text preprocessing (tokenization, stopwords, stemming)
* **Scikit-learn** – ML model, TF-IDF, evaluation
* **Pandas** – Dataset handling
* **NumPy** – Numerical computations
* **Matplotlib / Seaborn** – Data visualization
* **Regex (re)** – Text cleaning
